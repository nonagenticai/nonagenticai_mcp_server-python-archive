# Toolkit access security

Runtime extension (2026-10-24): see [execution implementation, configuration and pending cluster gates](EXECUTION_RUNTIME.md). Schema head is `0004_execution_runtime`; execution remains disabled by default until combined acceptance and rollout. Earlier validation sections describe their original stage.

The three operational probes are public. Pure ASGI middleware protects every `/mcp` request, including mounted transports, direct/private-network traffic and session reconnect/deletion. The implemented authentication, operator keys, token handling, expiry/cache limits, aliases, scope restrictions and remaining execution gates are specified in [Authentication and bindings](AUTHENTICATION_BINDINGS.md). [Stateless FastMCP discovery and tenant publication](CATALOG_PUBLICATION.md) are implemented; production execution remains unavailable; old CRUD/version/backup/audit/info and token issuance handlers remain removed.

Tenant ownership is an explicit UUIDv7, independent of subject/license attribution. Repository queries include tenant ownership and exact IDs/versions. Composite foreign keys protect tenant-owned children. An operator-only path manages platform contracts and sharing grants using credentials unavailable to the runtime role. Knowing an ID or receiving a sharing grant does not confer modification rights.

Snapshots, files, and operation references are immutable. Database guards reject direct updates/deletion and late child additions. Readiness performs bounded SELECT queries only; application startup does not create/migrate/repair databases. Deploy with a migration owner and a runtime role without CREATE, ownership, platform writes, or counter-update privileges. `scripts/grant_runtime_role.py` grants the catalog and access DML needed by tenant lifecycle operations; it does not create roles or grant membership in the migration owner.

Uploaded manifests cannot select transport destinations outside configured aliases, include arbitrary transport credentials, install dependencies, choose unapproved mutable image tags, or execute code in the API. Packages contain UTF-8 text entries only; metadata describing links/archives is rejected. Paths, byte counts, file counts, hashes, entrypoints, JSON dialect, local references, and validation complexity are bounded. Schema regex/format/dynamic/external resolution are unsupported. Contract syntax validation does not enforce runtime broker policy; execution remains unavailable until that policy and isolation exist.

The image omits development tests, credentials, worktrees, Node, and obsolete gateway/OAuth/Claude packages. Public health responses contain neither catalog data nor exception text. Credential values and raw binding/license tokens are never stored. Bindings store only SHA-256 token digests; access-event audit is append-only. The authenticated broker/Kata boundary and its release gates follow separately.

Publication audit includes exact artifact versions and rolls back with catalog changes. Provider lookup and invocation re-resolve live binding authority; signed cursors never widen the selection. Incoming bearer headers are stripped before FastMCP context creation. SDK tool-definition caching and optional task/app/resource/prompt handlers are bypassed in the pinned adapter. Only tools with no change-notification capability are advertised.
